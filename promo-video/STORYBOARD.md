## v2 (104 s) — original plan

## What the codebase says the product is

Traced end to end in the repo, then verified live (see "Verification" below):

1. A student types a question in the composer and picks **Deep Visual Dive**.
2. `session:start` over Socket.IO → `generateTimeline()` runs the agent loop
   (planning → scene graph → cinematic choreography). The server streams its
   real stage messages: *Running autonomous visual planning loop… / Finalizing
   scene graph pipeline… / Choreographing cinematic experience…*
3. `teaching:timeline` delivers a step-by-step lesson. The canvas engine
   (SceneOrchestrator → GSAP master timeline → D3 plugins) draws each step;
   the Session panel shows explanation + navigation; the control bar plays,
   pauses and steps.
4. **The differentiator — contextual doubts.** The student pauses and asks
   about the step in front of them. The client sends a snapshot of *what is on
   the canvas right now*; the DeltaAgent answers and returns visual commands
   that target real on-screen elements (here: the exact array cell holding 5),
   without restarting or replacing the lesson. Resume continues from that step.

**The "never seen an AI tutor do that" moment:** you ask *"why does 5 keep
moving right?"* and the answer lights up the 5 on the board. The film builds
toward it.

## Creative direction

- **Idea:** *Some answers need a board.* Words vs. a board that explains itself.
- **Look:** TutorBoard's own language — near-black, warm off-white, Geist,
  the dot-grid canvas, the isometric cube logo. One accent: **amber = insight**,
  used only where understanding happens (the highlighted cell, the tagline).
- **Rules:** real interface only (frame-accurate captures, 4K source for macro
  crops). Film-level additions are cinematography (camera, depth, light), a
  virtual cursor at the real element positions, and typography — never fake UI.
- **Sound:** original, synthesized in code (no licensed or paid assets).
  90 BPM → one beat = 20 frames, so every cut and cue lands on the grid.

## Honesty guardrails

- Stage messages are verbatim strings the server emits.

## Verification of the product flow (done before capture)

Running the app surfaced bugs that blocked this exact flow. Each was fixed in
the app and re-verified live (guest → Deep Visual Dive → steps → doubt → resume):

- First Deep Visual Dive question was routed to the doubt pipeline (`Home.jsx`)
- Submitting a doubt from chat wiped the live lesson (`Home.jsx`)
- Guest lessons crashed on an ObjectId cast (`pedagogyEngine.js`)
- Progress metadata streamed as narration text crashed the app (`sockets/utils.js`, `NarrationBar.jsx`)
- Every step's objects drawn at once (`objectIds` ignored) (`SceneOrchestrator.ts`)
- Lesson canvas double-scaled and clipped (`CinematicStage.jsx`)
- Missing store actions crashed every doubt answer (`sceneSlice.js`, `sessionSlice.js`)
- Lesson UI unmounted while a doubt was processed / when paused (`TeachingSession.jsx`)
- Doubt answers were never displayed — added the answer card (`SessionGuide.jsx`)
- Next Step dead after any doubt (`useTeachingMachine.js`)
- Lesson never continued after Resume (stuck in RESUMING) (`navigation.js`)
- Doubt input never focused; Space toggled playback while typing (`UnifiedControlBar.jsx`, `TeachingSession.jsx`)
- Doubt snapshot listed off-screen elements; callouts misplaced (`CanvasStateSnapshot.ts`, `CanvasEngine.ts`, `AuxPlugin.ts`, `primitives.ts`, `LayoutEngine.ts`)
- MongoDB credentials printed to logs (`bootstrap.ts`); Groq fallback 404s and `AI_MODEL` ignored (`llmClient.ts`)

Making the "any subject" sequence possible (found while scouting maths/physics/ML/chemistry):

- Non-DSA lessons rendered an empty board: the canvas engine ignored the text/equation/shape
  nodes the server asks the model for — new `ContentPlugin.ts` draws them (KaTeX equations)
- Every lesson's first generation was rejected (schema/required-key mismatch) and the retry lost
  step titles and narration — explicit output shape in the lesson prompt (`agentLoop.ts`)
- Physics simulations never reached the client (`simulationHtml` dropped by the payload) (`sockets/utils.js`)
- Replay did nothing; a lesson's first step never animated in (`AgentCanvasRenderer.jsx`)
- **New capability:** a `plot` node (function curves, data points, marked points; safe expression
  evaluator in `mathExpr.ts`) so maths, physics and ML lessons can show real graphs
